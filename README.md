# Contábol

https://contabol.github.io/

- `/` portada: elegir entre la app para Android y el panel web.
- `/descargar/` descarga del APK (`descargar/Contabol.apk`) y cómo instalarlo.
- `/panel/` el panel web para la PC (se abre en el navegador y se puede instalar).
- `/app/` dirección anterior del panel: redirige a `/panel/`.
- `version.json` y `contabol-X.Y.Z.zip`: actualizaciones en vivo de la app instalada.

Aquí no hay datos personales: los movimientos de cada persona se guardan en su cuenta, no en este sitio.

Se publica desde `contabol/app` con `npm run publicar -- "Qué cambió"`.
